# Team Stitch Pros Website

Welcome to the Team Stitch Pros website project! This is a modern, professional website built to showcase our custom sportswear, team apparel, and patch services.

## 🎯 Project Overview

This website represents Team Stitch Pros' commitment to quality and craftsmanship in custom sportswear and apparel. The site is designed to be fast, user-friendly, and effective at converting visitors into customers.

## 🚀 Quick Start

### Prerequisites

- Node.js version 20 or higher (currently using v24.4.1)
- Modern web browser (Chrome, Firefox, Safari, Edge)

### Installation & Running

1. **Install dependencies**:

   ```bash
   npm install


   ```

2. **Start development server**:
   npm run dev
